# 도구 통합 패널

[한국어](./도구_통합_패널_사용_가이드.md) · [English](./en/tool-integration-panel.md)

업데이트 기준: 2026-06-05

도구 통합 패널은 설정 탭 안의 운영 화면이다. 기능을 만드는 곳이 아니라 provider, tool, rag 상태를 관측하고 필요한 제어 요청을 보내는 곳이다.

![설정 탭](./assets/readme/dashboard-settings-tab.png)

## 보는 순서

1. 상태 요약에서 문제가 있는 도메인을 찾는다.
2. Provider 상태에서 키 누락, CLI 인증, 최근 오류를 확인한다.
3. Guard 관측에서 검색/RAG 응답이 왜 통과되거나 차단됐는지 본다.
4. 제어 요청으로 필요한 domain/action만 보낸다.
5. 결과 확인에서 status, duration, reason을 본다.

## 주요 도메인

| 도메인 | 예시 |
|---|---|
| `sessions` | list, history, send |
| `cron` | status, create, toggle, delete |
| `browser` | status, start, stop, tabs, navigate, open, focus, close (기본 `auto`: Playwright 실제 Chromium 우선, 실패 시 stub fallback) |
| `telegram` | command simulation |
| `web` | search, fetch |
| `memory` | search, get, rebuild |
| `doctor` | fix preview, fix apply |
| `cleanup` | preview, apply |

## 브라우저 도구 사용

일반 사용자는 대화 탭이나 코딩 탭에 자연어로 입력한다. 데스크톱 Ask 화면이나 Build 화면에서 자연어로 입력하면 브라우저 intent가 자동 감지된다.

예시:

- `네이버 열어줘`
- `유튜브 새 탭으로 열어줘`
- `github.com 열어줘`
- `브라우저 열어줘`
- `브라우저 닫아줘`

이 입력은 LLM 답변이나 코딩 실행 전에 브라우저 intent로 감지된다. 기본 `auto` 모드는 실제 Playwright 브라우저 컨텍스트를 시작한다. 탐색 화면의 브라우저에서 열린 페이지와 캡처를 확인할 수 있다.

운영자가 직접 제어할 때만 Settings 화면의 도구 통합 패널을 쓴다. 제어 요청 섹션에서 `browser.status`, `browser.navigate` 등 domain/action 요청을 보낼 수 있다.

기본값 `auto`는 Playwright를 사용한다. 전용 Chromium 실행 파일이 없으면 설치된 Chrome을 시도하며, 실행할 수 없으면 오류를 반환한다. 가짜 탭이나 가짜 캡처로 성공을 표시하지 않는다.

## 환경변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `OMNUX_BROWSER_TOOL_MODE` | `auto` | `auto`, `playwright`: 실제 실행. `off`: 비활성. 이전 `stub` 값은 비활성 오류를 반환 |
| `OMNUX_BROWSER_HEADLESS` | `true` | Playwright 브라우저 headless 실행 여부 |
| `OMNUX_CANVAS_TOOL_MODE` | `auto` | 실제 캔버스. `off`/이전 `stub` 값은 비활성 오류 반환 |
| `OMNUX_BROWSER_CHANNEL` | 빈 값 | 사용할 Chromium 계열 채널. 비워 두면 전용 Chromium, 없을 때 Chrome 시도 |

## 탐색과 캔버스

- 탐색 본문은 웹 검색·페이지 읽기와 브라우저·캔버스·작업 기록의 접이식 섹션으로 구성한다. 자료는 질문으로 전달할 수 있다.
- 캔버스 eval은 실제 DOM에서 JavaScript를 실행한다. snapshot은 실제 PNG/JPEG 데이터를 반환하며, 화면 숨김은 내용을 보존한다.
- A2UI는 v0.9/v0.9.1의 생성·구성 갱신·데이터 갱신·삭제 핵심 메시지, 데이터 바인딩과 action event를 처리한다. 전체 Basic Catalog 규격 준수를 주장하지 않는다. Text는 평문/제목을 표시하며, 지원하지 않는 함수·아이콘·카탈로그는 오류를 반환한다.
- `sessions_send`는 메시지 저장 접수다. 새 응답을 생성하지 않으며 과거 답변을 반환하지 않는다. 선택한 작업의 계속하기 버튼으로 원래 질문/빌드 흐름을 연다.
- 검증: `node scripts/check-gateway-runtime-contract.mjs --explore-only`. Node.js, Playwright와 실행 가능한 Chromium/Chrome이 필요하다.

참고: [Playwright 브라우저](https://playwright.dev/docs/browsers), [A2UI v0.9.1](https://a2ui.org/specification/v0.9.1-a2ui/).
