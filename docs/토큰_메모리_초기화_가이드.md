# 토큰과 메모리 초기화

[한국어](./토큰_메모리_초기화_가이드.md) · [English](./en/token-memory-reset.md)

업데이트 기준: 2026-09-12

omnux는 최근 대화, 메모리 노트, 검색 결과를 필요한 경우에만 문맥으로 붙인다. 답변이 자꾸 옛 문맥에 끌려가면 먼저 메모리를 확인한다.

## 데스크톱에서 초기화

| 위치 | 버튼 |
|---|---|
| 질문 화면 > 참고 자료 탭 | **대화 메모리 초기화** |
| 설정 > 데이터 > 메모리 노트 | **메모리 비우기** |

둘 다 확인 창에서 한 번 더 묻는다. 초기화한 뒤 새 질문으로 다시 확인한다.

## 텔레그램에서 초기화

```text
/memory clear
메모리 초기화해줘
```

## 판단 기준

- 짧은 인사나 단순 수식에는 검색과 메모리를 붙이지 않는 것이 정상이다.
- 최신 정보를 묻는 질문에는 검색 evidence가 붙을 수 있다.
- 프로젝트 코드 질문은 AGENTS와 필요한 파일 문맥이 우선이다.

메모리 노트 원본은 `~/.omnux/memory-notes/`에 있다. 초기화 전에 남겨야 할 내용이 있으면 **설정 > 데이터 > 백업**으로 먼저 내보낸다.
