# Token and Memory Reset

[한국어](../토큰_메모리_초기화_가이드.md) · [English](./token-memory-reset.md)

Updated: 2026-09-12

omnux attaches recent conversation, memory notes, and search results only when needed. If answers keep getting pulled toward old context, check memory first.

- Desktop: **대화 메모리 초기화** (Clear conversation memory) in the Ask screen's References tab, or **메모리 비우기** (Clear memory) in **Settings > Memory**. Both ask for confirmation.
- Telegram: `/memory clear` or "메모리 초기화해줘".

Short greetings and simple math normally get no search or memory context. Up-to-date questions may carry search evidence, and project code questions prioritize AGENTS and the relevant files.
