# omnux 사용법

[한국어](./사용법_빠른시작.md) · [English](./en/usage.md)

업데이트 기준: 2026-06-05

이 문서는 데스크톱 앱과 웹 대시보드에서 실제로 자주 쓰는 기능을 묶어 설명한다. 텔레그램 봇 슬래시 명령·inline 버튼·음성 첨부·다중 user allowlist 등은 [텔레그램_봇_가이드.md](./텔레그램_봇_가이드.md) 참고.

처음 설치하거나 새 환경에서 실행할 때는 `./scripts/omnux setup`을 먼저 실행한다. 이 setup은 의존성 확인/설치, 미들웨어 빌드, `npm test`, 실행기 등록을 처리한다.

## Home

Home 화면은 대시보드의 시작점이다.

- **Active Projects**: 등록된 프로젝트 목록에서 대표 프로젝트를 표시한다.
- **Continue**: 최근 작업한 항목으로 바로 이동한다.
- **Recent Activity**: 런타임 WebSocket 이벤트 기반 타임라인을 표시한다.
- **Resource Usage**: `metrics`/`metrics_stream` 기반 CPU/메모리/프로세스 카드를 표시한다.

## Ask (대화)

![대화 탭](./assets/readme/dashboard-chat-tab.png)

Ask 화면은 단일 모델, 오케스트레이션, 다중 LLM 비교를 같은 화면 안에서 바꿔 쓴다.

- **단일 모드**: 한 모델이 답변한다.
- **오케스트레이션 모드**: 기획/개발/검증/수정 역할을 나눠 진행한다.
- **멀티 모드**: 여러 provider/model이 동시에 답변하고 결과를 비교한다.
- **마크다운 렌더링**: `react-markdown`으로 표, 코드, 링크를 렌더한다.
- **Think+**: 추론 모드 토글. 깊은 분석이 필요한 질문에 쓴다.
- **RAG preflight**: 입력을 분석해 memory/code/web/session 검색 후보를 추천하고, 사용자가 명시적으로 실행할 수 있다.
- **Vision**: 이미지 파일을 선택해 Vision preflight를 실행한다. provider 후보와 readiness를 확인한다.
- **Token usage**: 대화별/메시지별 token 사용량과 source(exact/estimated)를 표시한다.
- **Adaptive Compression**: 대화가 길어지면 백엔드가 자동 압축한다. 압축 시스템 메시지와 linked memory를 표시한다.

브라우저 실행 요청은 대화 입력에서 바로 처리된다. `네이버 열어줘`, `github.com 열어줘`, `브라우저 닫아줘`처럼 쓰면 LLM 호출 전에 브라우저 intent로 감지한다.

스킬 이름을 직접 말하면 해당 스킬이 활성화되고, 사용자가 중지할 때까지 같은 대화에서 유지된다. 이 흐름은 텔레그램에서도 같다. 미들웨어 재시작 후에도 마지막 활성 스킬이 자동 복원된다.

한 메시지에 스킬 이름이 2개 이상 들어가면 거부 메시지를 받는다. UI 드롭다운으로 스킬을 선택해도 프롬프트에서 다른 스킬을 명시하면 프롬프트가 우선한다.

## Build (코딩)

![코딩 탭](./assets/readme/dashboard-coding-tab.png)

Build 화면은 모델 답변을 파일로 끝내지 않는다. 실행 폴더를 만들고, 파일 생성, 실행 명령, stdout/stderr, 검증 결과, 최근 결과 snapshot을 남긴다.

- **단일 코딩**: 한 모델이 끝까지 구현하고 검증한다.
- **오케스트레이션 코딩**: 기획, 개발, 검증, 수정 역할을 나눠 진행한다.
- **멀티 코딩**: 여러 provider/model이 독립 폴더에서 완주하고 결과를 비교한다.
- **롤백**: 코딩 실행 전 workspace baseline을 저장하고, 변경이 있으면 rollback snapshot을 생성한다. 복원은 rollback ID 기반으로 실행한다.
- **최신 결과 실행**: 이전 코딩 결과를 다시 실행할 수 있다.

기본 실행 폴더는 `workspace/coding/runs/<timestamp>-<mode>-<suffix>/`다.

## Logic (로직 그래프)

![로직 탭](./assets/readme/dashboard-logic-tab.png)

Logic 화면은 `logic.graph.v1` 그래프를 관리하고 실행한다. 대화, 코딩, 루틴, 도구 노드를 연결해 흐름을 만든다.

- **그래프 목록**: 저장된 그래프 목록을 표시한다.
- **구조 뷰**: 선택한 그래프의 노드(type/title/config)와 엣지(source→target)를 표시한다.
- **실행**: 그래프를 실행하고, 실행 snapshot의 노드별 상태를 표시한다.
- **저장/삭제/취소**: 그래프를 저장, 삭제, 실행 중 취소할 수 있다.
- **복구 후보**: 미들웨어 재시작 후 미완료 실행 snapshot을 조회할 수 있다.

실행 결과는 `workspace/.runtime/logic/` 아래에 남는다.

## Explore (탐색)

Explore 화면은 웹 검색, URL 가져오기, 세션 관리, 에이전트 스폰을 제공한다.

- **웹 검색**: `web_search` → 검색 결과와 provider 배지를 표시한다.
- **URL 가져오기**: `web_fetch` → HTTP status, 길이, 본문을 표시한다.
- **세션**: 세션 목록/이력, 선택 세션 후속 메시지 전송.
- **에이언트 스폰**: 새 세션을 생성하고 큐/active/breaker 상태를 표시한다.
- **Browser/Canvas**: 브라우저 상태/시작/종료와 캔버스 표시/숨김.

## Automate (루틴)

![루틴 탭](./assets/readme/dashboard-routines-tab.png)

Automate 화면은 루틴 CRUD와 생성 wizard를 제공한다.

- **루틴 목록**: 등록된 루틴과 toggle 상태를 표시한다.
- **실행**: 즉시 실행 또는 예약 실행.
- **생성 Wizard**: 3-step progressive disclosure (요청 → 스케줄 → 고급 설정).
  - 요청: 자연어로 루틴 내용 작성
  - 스케줄: kind(즉시/크론/간격), 시각, 요일, 일자 설정
  - 고급: runImmediately, notifyTelegram 설정
- **미리보기**: 생성 전에 백엔드에서 루틴 구조를 미리 확인할 수 있다.

예약 실행 결과는 루틴별 Telegram 응답 설정에 따라 전송된다.

## Projects

Projects 화면은 로컬 프로젝트를 등록하고 관리한다.

- **프로젝트 목록**: `projects_state` 기반으로 등록된 프로젝트를 표시한다.
- **CRUD**: 프로젝트 생성, 수정, 삭제.
- **대표 프로젝트**: 한 프로젝트를 대표로 지정할 수 있다.
- **Touch**: 프로젝트 열기 시 마지막 사용 시각을 갱신한다.

프로젝트 상태는 `~/.omnux/projects.json`에 저장된다.

## Settings

![설정 탭](./assets/readme/dashboard-settings-tab.png)

Settings 화면은 여러 탭으로 구성된다.

- **Memory & Backup**: 메모리 노트 목록/검색/이름 변경/삭제/비우기, 메모리 상세 읽기, FTS 인덱스 재구축, portable backup export/import preview/apply.
- **Models & Services**: Groq/Copilot 모델 선택·적용·새로고침, CLI 어댑터 상태, API 키 저장/삭제, Gemini 토큰·Copilot Premium 쿼터, Telegram Bot Token/Chat ID 연동.
- **Memory 검색 결과**: tier 배지(working/short_term/episodic/long_term), source, line 범위를 표시한다.

외부접속 클라이언트는 OTP 없이 제한 모드로 들어오며, 읽기 중심 조회와 모델/라우팅 설정만 허용한다.

## Operations (운영)

Operations 화면은 환경 진단, Git 자동화, 계획/태스크 상태를 제공한다.

- **Doctor / 환경 진단**: `doctor_get_last`, `doctor_run`, `doctor_fix_preview`로 환경 상태를 확인한다. ok/warn/fail/skip 카운트와 체크별 상태를 표시한다. `doctor_fix_apply`는 위험 운영 명령으로 현재 비활성이다.
- **Git Automation**: `git_automation_snapshot_get`으로 branch, 변경 파일, readiness/publish 상태를 표시한다. `git_operation_preview`로 브랜치 생성, 커밋, 푸시, PR 생성 미리보기를 요청하고, 승인 게이트를 거쳐 apply할 수 있다.
- **Plan / Task 상태**: `plan_list`, `task_graph_list` read-only 요약 카드.

## Activity

Activity 화면은 런타임 WebSocket 이벤트 기반 타임라인과 세션 리플레이를 제공한다.

- **이벤트 타임라인**: 실시간 WS 이벤트를 시간순으로 표시한다.
- **Session Replay**: `session_replay_get`으로 대화 메시지, LLM telemetry, agent event 타임라인을 조회한다. summary와 metadata만 표시하고 원문은 선택적으로 볼 수 있다.

## Insights (인사이트)

Insights 화면은 다양한 readiness와 상태 스냅샷을 제공한다.

- **Telemetry**: LLM 호출 기록을 provider/model/status/token/시간순으로 조회한다.
- **Semantic Search Readiness**: FTS/벡터 검색 상태, 임베딩 모델 후보를 표시한다.
- **Local LLM Discovery**: 로컬 엔드포인트(Ollama/LM Studio)의 latency, 모델, 오프라인 모드 상태를 표시한다.
- **Git Time Machine**: 저장소 상태, checkpoint 목록, rollback 후보를 표시한다.
- **Commit Learning**: 최근 커밋 metadata, intent rollup, 파일 hotspot을 표시한다.
- **Self Improvement**: 백엔드가 제안하는 개선 사항을 카드형으로 표시한다.
- **MCP Servers**: 워크스페이스 MCP 설정 파일을 스캔해 발견된 서버를 표시한다.
- **Terminal Readiness**: shell/toolchain 상태를 표시한다.
- **Routing Policy**: 라우팅 정책, 최근 결정, 로컬 LLM readiness를 표시한다.

## Agents (에이전트)

Agents 화면은 에이전트 버스, 생명주기, 멀티 에이전트 추적을 제공한다.

- **Agent Bus**: 메시지 기록, 공유 보드 upsert, lifecycle event 저장, group command 메시지 저장.
- **Multi-Agent Trace**: 에이전트 간 messages/board/lifecycle을 시각화용 구조로 투영한다.
- **Agent Watchdog**: active run inventory와 timeout/stale 상태를 표시한다.
- **Agent Worktree**: ACP spawn worktree 목록과 clean/dirty/conflict 상태를 표시한다.

## Skills (스킬)

![스킬 탭](./assets/readme/dashboard-skills-tab.png)

스킬은 `.omni/skills/**/SKILL.md`와 `~/.omnux/skills/**/SKILL.md`에서 읽는다. 대화/코딩 입력창의 스킬 배지로 활성화/해제할 수 있다.

## Routing (라우팅)

Routing 화면은 라우팅 정책 관리와 로컬 LLM readiness를 제공한다.

- **라우팅 정책**: 현재 provider fallback 체인을 조회/저장/초기화한다.
- **최근 결정**: 카테고리/요청 provider/결과 provider/결정 시각/사유를 카드로 표시한다.
- **로컬 LLM**: endpoint 수, 모델 수, 오프라인 모드 상태, readiness check를 표시한다.

## Command Palette

⌘K으로 Command Palette를 열어 빠르게 액션을 실행할 수 있다.

## 테마

상단 툴바의 테마 토글로 3가지 테마를 전환할 수 있다.

- **Glass** (기본): 반투명 배경 + backdrop-blur, 파스텔 blob
- **Light**: 깨끗한 오프화이트 + 섬세한 그림자
- **Dark**: 따뜻한 다크 톤 + 인디고 glow
