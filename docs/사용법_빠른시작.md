# omnux 사용법

[한국어](./사용법_빠른시작.md) · [English](./en/usage.md)

업데이트 기준: 2026-09-12

데스크톱 앱에서 자주 쓰는 화면만 짧게 정리했다. 설치와 실행은 [QUICKSTART.md](./QUICKSTART.md), 텔레그램은 [텔레그램_봇_가이드.md](./텔레그램_봇_가이드.md)를 본다.

## 화면 구성

왼쪽 레일에서 영역을 고르고 서브패널에서 화면을 고른다. 좁은 폭에서는 상단 메뉴 버튼으로 내비를 연다. ⌘K(Windows/Linux는 Ctrl+K)로 커맨드 팔레트를 연다.

| 영역 | 화면 |
|---|---|
| 홈 | 홈 |
| 워크스페이스 | 질문, 빌드, 자동화, 탐색, 리뷰 |
| 프로젝트 | 프로젝트, 작업, 노트 |
| 엔진 | 에이전트, 도구, 확장, 라우팅, 규칙 |
| 모니터 | 활동, 로그, 상태 |
| 설정 | 설정 |

## 홈

입력창에 바로 요청을 적는다. 아래 바로가기(자동화, 로직, 스킬, 계획, 노트)로 새 항목을 만들고, 하단 **이어서 작업하기**와 **활성 프로젝트**에서 최근 작업으로 돌아간다.

## 질문

탭: 대화 · 모델 · 참고 자료 · 기록

- 모드는 싱글, 오케스트레이션, 멀티다. 멀티는 여러 provider 답변을 나란히 비교한다.
- Enter로 보내고 Shift+Enter로 줄을 바꾼다. 한글 조합 중 Enter는 보내지 않는다.
- 파일과 이미지를 첨부한다. 이미지는 형식과 모델 지원을 먼저 확인한다.
- 답변은 노트, 작업, 빌드, 자동화로 넘길 수 있다.
- `네이버 열어줘`, `브라우저 닫아줘` 같은 요청은 LLM 호출 전에 브라우저 명령으로 처리한다.
- 스킬 이름을 말하면 그 스킬이 켜지고, 끌 때까지 같은 대화에서 유지된다.

## 빌드

탭: 빌드 · 설정 · 참고 · 기록

1. 만들 내용을 적고 **만들기**를 누른다. Cmd/Ctrl+Enter로도 보낸다. 파일은 최대 6개, 전체 10MB까지 첨부한다.
2. 진행 중에는 **작업 중단**으로 멈춘다. 다음 요청은 미리 적어 둘 수 있다.
3. 결과의 요약·파일·프로그램 출력을 읽는다. HTML은 **미리 보기**로 연다.
4. **다시 실행하기**로 입력을 넣어 결과를 다시 실행한다.
5. 멈춘 작업은 **중단한 요청 이어 쓰기**로 원래 요청과 모델을 되살린다.

모델·언어·프로젝트 이름은 **모델과 작업 설정**, 스킬·노트는 **스킬과 참고 노트**에서 고른다. 지난 빌드는 **저장한 빌드**에서 다시 연다. 실행 폴더는 `workspace/coding/runs/`다.

빌드에서도 `네이버 열어줘`, `브라우저 닫아줘`처럼 적으면 코딩 실행 전에 브라우저 명령으로 처리한다.

## 자동화

1. **새 자동화**에서 할 일과 주기(매일·매주·매월)·시간을 정한다. 이름·시간대·실행 방식·재시도·텔레그램 알림은 **이름과 추가 설정**에 있다.
2. **자동화 저장**은 예약만 저장한다. 바로 돌리려면 **지금 실행**을 누른다.
3. 자동화를 고르면 최근 실행 결과가 보인다. 이전 실행과 원본 기록은 접힌 영역에 있다.
4. **예약 끄기**는 다음 예약을 막는다. 이미 시작한 실행은 취소하지 않는다.

텔레그램 알림은 기본으로 꺼져 있다. 정의는 `~/.omnux/routines.json`, 실행 결과는 `workspace/coding/routines/`에 남는다.

## 탐색

탭: 웹 찾기 · 브라우저 · 캔버스 · 기록

웹 검색과 URL 가져오기, 브라우저 제어, 캔버스 표시를 한 화면에서 한다. 브라우저는 새 임시 컨텍스트에서 setup이 설치한 Playwright Chromium을 쓰고, 없으면 설치된 Chrome을 쓴다. 실행할 수 없으면 오류를 반환하고 가짜 성공을 표시하지 않는다.

## 리뷰

Safe Refactor 화면이다. 탭 순서대로 1. 파일 → 2. 바꿀 내용 → 3. 확인·적용을 진행한다. 적용 직전에 파일 상태를 다시 확인한다.

## 프로젝트 · 작업 · 노트

| 화면 | 탭 | 내용 |
|---|---|---|
| 프로젝트 | 목록 · 추가 | 로컬 프로젝트 등록과 관리 (`~/.omnux/projects.json`) |
| 작업 | 목록 · 새 계획 | 계획 생성, 리뷰, 승인, 실행 |
| 노트 | 남기기 · 결정 · 확인 · 메모 · 이어보기 | 학습, 결정, 검증 기록과 handoff |

## 엔진

| 화면 | 탭 |
|---|---|
| 에이전트 | 실행 중 · 흐름 · 공유 기록 · 작업 폴더 · 기록 남기기 |
| 도구 | 전체 · 프로젝트 · 전역 스킬 (`.omni/skills/`, `~/.omnux/skills/`) |
| 확장 | 훅 · 승인 · 규칙 · 플러그인 |
| 라우팅 | 작업별 경로 · 최근 선택 · 로컬 모델 |
| 규칙 | 로직 그래프 목록 · 그림 · 속성 · 실행 |

## 모니터

| 화면 | 탭 |
|---|---|
| 활동 | 이 세션 기록 · 세션 타임라인 |
| 로그 | 모델 호출 · 진단 |
| 상태 | 연결 · 점검 · 작업 · 도구 |

상태 화면의 **점검 > 환경 진단**에서 Doctor 결과와 복구를, **도구 > 정리**에서 산출물 정리를 한다.

## 설정

탭: 일반 · 연동 · 모델·키 · 메모리 · 정보

모델·키 탭에서 provider별 모델 선택, 연동 키, CLI 인증, 우선순위, 사용량을 관리한다. 메모리 탭에서 메모 관리, **메모리 비우기**, portable 백업을 한다. 외부접속 토글도 설정에 있다.

## 테마

Light(기본), Glass, Dark 세 가지다. 상단 테마 버튼으로 바꾼다.
