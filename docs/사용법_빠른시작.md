# 사용법

[한국어](./사용법_빠른시작.md) · [English](./en/usage.md)

업데이트 기준: 2026-09-12

데스크톱 앱의 각 화면 인터랙션 및 워크플로를 안내합니다. 초기 설치와 실행은 [5분 시작](./QUICKSTART.md), 모바일 원격 제어는 [텔레그램 봇 가이드](./텔레그램_봇_가이드.md)를 참고하세요.

## 화면 구성

좌측 내비게이션 레일에서 영역을 선택한 뒤 서브패널에서 세부 화면으로 진입합니다. 화면 폭이 좁은 뷰포트에서는 상단 메뉴 버튼으로 내비게이션 드로어를 열 수 있습니다. `⌘K`(Windows/Linux 환경은 `Ctrl+K`)를 눌러 커맨드 팔레트를 즉시 호출할 수 있습니다.

| 영역 | 화면 |
|---|---|
| 홈 | 홈 |
| 워크스페이스 | 질문, 빌드, 자동화, 탐색, 리뷰 |
| 프로젝트 | 프로젝트, 작업, 노트 |
| 엔진 | 에이전트, 도구, 확장, 라우팅, 규칙 |
| 모니터 | 활동, 로그, 상태 |
| 설정 | 설정 |

## 홈

중앙 프롬프트 입력창에 수행할 작업을 바로 입력합니다. 하단 바로가기(자동화, 로직, 스킬, 계획, 노트)로 신규 워크플로를 시작하거나, **이어서 작업하기** 및 **활성 프로젝트** 영역에서 최근 작업 컨텍스트로 복귀할 수 있습니다.

## 질문

탭: 대화 · 모델 · 참고 자료 · 기록

- 모드는 싱글, 오케스트레이션, 멀티를 지원합니다. 멀티 모드에서는 여러 LLM provider의 답변을 나란히 두고 비교할 수 있습니다.
- Enter로 전송하고 Shift+Enter로 줄바꿈합니다. 한글 IME 조합 중의 Enter는 전송되지 않습니다.
- 파일과 이미지를 드래그 앤 드롭으로 첨부할 수 있습니다. 이미지는 해당 모델의 멀티모달 지원 여부를 먼저 점검합니다.
- 생성된 답변을 클릭 한 번으로 노트, 작업, 빌드, 자동화 워크플로로 전달할 수 있습니다.
- `네이버 열어줘`, `브라우저 닫아줘` 같은 요청은 LLM 호출 전에 브라우저 명령으로 처리합니다.
- 특정 스킬 이름을 언급하면 해당 스킬이 활성화되며, 명시적으로 비활성화할 때까지 세션 안에서 지속 적용됩니다.

## 빌드

탭: 빌드 · 설정 · 참고 · 기록

1. 구현할 요구사항을 입력하고 **만들기**를 누릅니다 (`Cmd/Ctrl+Enter` 단축키 지원). 파일은 최대 6개, 총합 10MB까지 첨부 가능합니다.
2. 실행 중에는 **작업 중단** 버튼으로 즉시 중지할 수 있으며, 다음 요청을 대기열에 미리 작성할 수 있습니다.
3. 실행 완료 후 결과 요약, 생성 파일 목록, 프로그램 콘솔 출력을 확인합니다. HTML 산출물은 **미리 보기**로 즉시 렌더링합니다.
4. **다시 실행하기**를 통해 입력을 조정하여 코드를 재구동할 수 있습니다.
5. 중단된 세션은 **중단한 요청 이어 쓰기**로 원래의 프롬프트와 모델 설정을 복원합니다.

모델 및 구현 언어, 대상 프로젝트는 **모델과 작업 설정**에서 지정합니다. 스킬과 참고 자료는 **스킬과 참고 노트**에서 선택할 수 있습니다. 과거 빌드 이력은 **저장한 빌드**에서 다시 확인 가능하며, 실행 디렉터리는 `workspace/coding/runs/`에 보존됩니다.

빌드에서도 `네이버 열어줘`, `브라우저 닫아줘`처럼 적으면 코딩 실행 전에 브라우저 명령으로 처리합니다.

## 자동화

탭: 목록 · 새 자동화(편집) · 결과

1. **새 자동화**에서 실행할 작업 내용과 반복 주기(매일·매주·매월), 실행 시각을 지정합니다. 루틴 이름, 타임존, 실행 모드, 재시도 횟수, 텔레그램 알림 여부는 **이름과 추가 설정**에서 구성합니다.
2. **자동화 저장**은 스케줄 등록만 수행합니다. 즉시 실행하여 검증하려면 **지금 실행**을 누릅니다.
3. 자동화 목록에서 특정 항목을 선택하면 최근 실행 결과가 표시되며, 이전 이력은 접힌 영역에서 열람할 수 있습니다.
4. **예약 끄기**를 통해 다음 주기의 실행을 일시 중단할 수 있습니다(현재 진행 중인 작업은 유지).

텔레그램 알림은 기본 비활성화 상태입니다. 자동화 정의는 `~/.omnux/routines.json`에 저장되고, 실행 결과물은 `workspace/coding/routines/`에 보존됩니다.

## 탐색

탭: 웹 찾기 · 브라우저 · 캔버스 · 기록

웹 검색, URL 내용 추출, 실제 브라우저 제어, 캔버스 뷰어를 단일 화면에서 제공합니다. 브라우저는 격리된 임시 세션에서 `omnux setup`으로 설치된 Playwright Chromium을 우선 사용하며, 부재 시 시스템에 설치된 Chrome을 사용합니다. 실행 환경이 충족되지 않으면 즉시 명확한 오류 원인을 반환합니다.

## 리뷰

Safe Refactor 화면이다. 탭 순서대로 1. 파일 → 2. 바꿀 내용 → 3. 확인·적용을 진행한다. 적용 직전에 파일 상태를 다시 확인한다. 자세한 내용은 [Safe Refactor](./SAFE_REFACTORING.md)에 있다.

## 프로젝트 · 작업 · 노트

| 화면 | 탭 | 하는 일 |
|---|---|---|
| 프로젝트 | 목록 · 추가(수정) | 로컬 프로젝트 등록과 관리 (`~/.omnux/projects.json`) |
| 작업 | 목록 · 새 계획 · 계획 · 실행 · 결과 | 계획 생성, 리뷰, 승인, 실행 |
| 노트 | 남기기 · 결정 · 확인 · 메모 · 이어보기 | 결정과 검증 기록, 다음 세션용 handoff |

작업 화면의 계획·실행·결과 탭은 해당 상태가 있을 때만 나타난다.

## 엔진

| 화면 | 탭 |
|---|---|
| 에이전트 | 실행 중 · 흐름 · 공유 기록 · 작업 폴더 · 기록 남기기 |
| 도구 | 전체 · 프로젝트 · 전역 (`.omni/skills/`, `~/.omnux/skills/`) |
| 확장 | 훅 · 승인 · 규칙 · 플러그인 |
| 라우팅 | 작업별 경로 · 최근 선택 · 로컬 모델 |
| 규칙 | 목록 · 그림 · 속성 · 실행 |

## 모니터

| 화면 | 탭 |
|---|---|
| 활동 | 이 세션 기록 · 세션 타임라인 |
| 로그 | 모델 호출 · 진단 |
| 상태 | 연결 · 점검 · 작업 · 도구 |

상태 화면의 **점검 > 환경 진단**에서 Doctor 결과와 복구를, **도구 > 정리**에서 산출물 정리를 한다.

탭: 일반 · 모델 · 보안 · 연동 · 데이터 · 정보

|---|---|
