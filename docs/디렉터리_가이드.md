## 보존 기준

`~/.omnux`는 영속 상태 원본이다. 대화, 계획, 노트북, 라우팅 정책, 세션 정보, 프로젝트 정의, 에이전트 통신, telemetry 추적, 메모리 노트가 들어 있으므로 삭제 전에는 반드시 보존 여부를 확인한다.

## 실행기

- `./scripts/omnux setup`: macOS/Linux에서 의존성 확인/설치, 미들웨어 빌드, 검증, 실행기 등록을 처리한다.
- `./scripts/omnux`: setup marker가 있으면 서버를 시작하고, 없으면 자동 setup을 먼저 시도한다.
- `./scripts/omnux shutdown`: 실행 중인 omnux 프로세스를 정리한다.
- `.\scripts\omnux.ps1 setup`: Windows에서 의존성 확인, 빌드, 검증을 처리한다.
