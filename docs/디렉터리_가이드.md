# 디렉터리 가이드

[한국어](./디렉터리_가이드.md) · [English](./en/directory-guide.md)

업데이트 기준: 2026-09-12

omnux의 표준 canonical 레이아웃은 `apps/`, `docs/`, `scripts/`, `workspace/`입니다. 모든 신규 코드는 이 canonical 경로 규칙을 준수하여 배치합니다.

## 루트

| 경로 | 내용 |
|---|---|
| `apps/omnux-middleware/` | .NET 9 미들웨어. WebSocket/HTTP, 텔레그램, 라우팅, 도메인 오케스트레이션 |
| `apps/omnux-middleware-tests/` | .NET 단위 테스트 |
| `apps/desktop/` | Tauri v2 데스크톱 앱. React 19 + TypeScript + Tailwind CSS v4 |
| `apps/omnux-sandbox/` | Python 실행기 (`executor.py`) |
| `apps/shared/` | 모델 레지스트리(`model-registry.json`), C# 생성기, 리뉴얼 대장 스크립트 |
| `docs/` | 한국어 문서. 영어 문서는 `docs/en/` |
| `scripts/` | `omnux` 실행기, Windows용 `omnux.ps1`·`omnux.cmd`, 계약·화면 검사 스크립트 |
| `plugins/` | 저장소에 둔 예시 플러그인 (`safety-basics`) |
| `deploy/` | macOS `launchd` plist, Linux `systemd` 유닛 |
| `.github/workflows/` | guard retry timeline, guard alert dispatch 회귀 워크플로 |
| `.omni/skills/` | 프로젝트 스킬 (`SKILL.md`) |
| `workspace/` | 작업 산출물 (git 추적 안 함) |
| `output/` | 검사 스크린샷과 픽스처 (git 추적 안 함) |

## 미들웨어

| 경로 | 내용 |
|---|---|
| `src/` | C# 원본. `CommandService`, `LlmRouter`, `Ws*CommandDispatcher` 31개, `*Policy` 100개 |
| `src/Application/` | 도메인 서비스. Coding, Routine, Doctor, Plan, TaskGraph, Extensions, Agents 등 |

## 보존 기준

`~/.omnux` 디렉터리는 시스템 영속 상태의 SSOT(단일 진실 공급원)입니다. 대화 내역, 실행 계획, 노트북, 라우팅 정책, 세션 메타데이터, 로컬 프로젝트, 에이전트 통신 로그, 사용량 계측(telemetry), 메모리 노트가 보관되므로 삭제 전 영향 범위를 반드시 확인해야 합니다. CLI 실행기 상태 파일은 `~/.omnux/cli/`에 저장됩니다.

디렉터리별 안전한 삭제 및 보관 기준은 [정리 기준](./CLEANUP.md)을 참고하세요.

## 실행기

| 명령 | 동작 |
|---|---|
| `./scripts/omnux setup` | 의존성 확인·설치, 빌드, `npm test`, 실행기 등록 |
| `omnux` | 데스크톱 앱 실행 (미들웨어 포함) |
| `omnux start` / `status` / `shutdown` | 미들웨어만 실행, 상태 확인, 전체 종료 |
| `.\scripts\omnux.ps1 setup` | Windows setup |
