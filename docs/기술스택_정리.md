# 기술 스택

[한국어](./기술스택_정리.md) · [English](./en/tech-stack.md)

업데이트 기준: 2026-06-02

omnux는 하나의 거대한 프레임워크가 아니라 역할별로 작은 런타임을 나눠 붙인 구조다.

| 영역 | 기술 | 이유 |
|---|---|---|
| 코어 런타임 | .NET 9 | metrics, guarded kill, WebSocket/HTTP, 텔레그램, 파일 상태, provider 라우팅, 도메인 오케스트레이션 |
| 대시보드 | HTML/CSS/JavaScript | 별도 번들러 없이 정적 파일로 배포 |
| 데스크톱 셸 | Rust + TypeScript + React | Tauri 앱 셸, 창 관리, 런타임 부트, UI 경계 |
| 실행기 | Python | 간단한 코드 실행과 검증 |
| 테스트/스크립트 | Node.js, npm scripts | 저장소 위생, 계약 검사, 프런트 문법 확인 |
| 상태 | JSON, Markdown, SQLite 일부 | 사람이 읽을 수 있는 운영 상태와 기록 |

## 언어 책임 경계

- Rust는 앱 셸(Window 관리)만 맡고, provider/API/상태/도메인 로직을 소유하지 않는다.
- TypeScript와 JavaScript는 데스크톱/대시보드 UI 셸과 계약 검증 스크립트에만 쓴다.
- Python은 샌드박스 실행과 코드 검증에만 쓴다.
- Node.js는 테스트, 위생 검사, 계약 검사에만 쓴다.
- 새 비즈니스 로직과 상태 오케스트레이션은 기본적으로 .NET 9 미들웨어가 전담한다.

## 원본 위치 경계

- .NET 9 런타임, 비즈니스 로직, 정책 코드는 `apps/omnux-middleware/src/`에만 둔다.
- 데스크톱 셸의 React/TypeScript 코드는 `apps/desktop/src/`에 두고, Rust 셸 코드는 `apps/desktop/src-tauri/src/`에 둔다.
- Python 코드는 `apps/omnux-sandbox/executor.py`에만 둔다.
- Node.js 계약 검사와 런너 코드는 `scripts/`에 둔다.
- 루트에는 Electron/Codex 번들 산출물인 `main.js`, `preload.js`, `worker.js`를 보관하지 않는다.
- 미들웨어 루트에는 코딩 스모크가 생성한 `main.py`, `main.js`, `main.c` 같은 작업 산출물을 보관하지 않는다.
- 새 코드를 만들 때는 위 경계를 넘기지 않는다.

## LLM 연동

- Gemini: API와 grounding 검색
- Groq: OpenAI 호환 HTTP
- Cerebras: HTTP API
- NVIDIA NIM: OpenAI 호환 chat completions
- Copilot: CLI 래퍼
- Codex: CLI/API 경로

## 프런트엔드 원칙

대시보드는 도구형 화면이다. 정보 밀도, 반복 사용, 모바일 입력 UX를 우선한다. landing page처럼 꾸미기보다 대화, 실행 결과, 설정, 로그가 빠르게 보이도록 구성한다.
