## 기본 검증

| 명령 | 기대 결과 |
|---|---|
| `python3 apps/omnux-sandbox/executor.py --code "print('ok')"` | `ok` 출력 |
| `dotnet build apps/omnux-middleware/Omnux.Middleware.csproj` | 미들웨어 빌드 성공 |
| `npm test` | 저장소 위생, 보안 경계, 화면/계약 테스트 통과 |
| `./scripts/omnux setup` | macOS/Linux 의존성 확인/설치, 빌드, 검증, 실행기 등록 |
| `curl -s http://127.0.0.1:8080/readyz` | 준비 상태 확인 |
| `dotnet run --project apps/omnux-middleware/Omnux.Middleware.csproj -- doctor --json` | doctor JSON 출력 |

Windows 기본 검증은 아래를 쓴다.

```powershell
.\scripts\omnux.ps1 setup
```

## 데스크톱 앱 검증

```bash
# Vite 빌드
npm run build --prefix apps/desktop

# Tauri 개발 모드 (미들웨어 먼저 실행 필요)
npm run tauri dev --prefix apps/desktop
```

데스크톱 앱은 미들웨어 WebSocket(기본 `ws://127.0.0.1:8080`)에 연결해야 동작한다. 미들웨어가 먼저 실행 중인지 확인한다.

## 계약 검사 스크립트

`scripts/` 아래 16개 계약 검사 스크립트가 있다. `npm test`가 모두 실행하지만, 범위를 줄여 확인할 때는 개별 스크립트를 직접 실행할 수 있다.

| 스크립트 | 검사 내용 |
|---|---|
| `check-tech-stack-contract.mjs` | 기술 스택 계약 |
| `check-repo-hygiene.mjs` | 저장소 위생 |
| `check-security-boundaries.mjs` | 보안 경계 계약 |
| `check-frontend-contracts.mjs` | 프런트엔드 타입 계약 |
| `check-ws-contracts.mjs` | WebSocket 메시지 계약 |
| `check-desktop-contracts.mjs` | 데스크톱 화면 계약 |
| `check-dashboard-contracts.mjs` | 대시보드 화면 계약 |
| `check-middleware-contracts.mjs` | 미들웨어 내부 계약 |

Phase 5 변경 전후에는 `npm test`를 통과시킨다. 범위를 줄여 확인할 때도 최소 `check-tech-stack-contract`와 `check-repo-hygiene`를 함께 실행한다.

## 수동 회귀 체크

- **Home**: Active Projects, Continue, Recent Activity, Resource Usage 카드 표시
- **Ask**: 단일/오케스트레이션/멀티 LLM 전환, 마크다운 렌더링, Think+ 토글, RAG preflight, Vision, Token usage
- **Build**: 실행 폴더 생성, 최근 결과 복원, 오케스트레이션/멀티 모드, 롤백 snapshot
- **Logic**: 그래프 저장/실행/삭제, 산출물 생성, 복구 후보 조회
- **Explore**: 웹 검색, URL 가져오기, 세션 관리, 에이전트 스폰, Browser/Canvas
- **Automate**: 루틴 CRUD, 즉시 실행, 예약 상태, 생성 Wizard, Telegram 전송 여부
- **Projects**: 프로젝트 CRUD, 대표 프로젝트 지정, Touch 갱신
- **Settings**: Memory/Backup, Models/Services, 외부접속 토글, 민감 설정 차단, provider 상태
- **Operations**: Doctor 진단, Git Automation snapshot/preview/apply, Plan/Task read-only
- **Activity**: 이벤트 타임라인, Session Replay
- **Insights**: Telemetry, Semantic Search Readiness, Local LLM, Git Time Machine, Commit Learning, Self Improvement, MCP, Terminal, Routing Policy
- **Agents**: Agent Bus, Multi-Agent Trace, Watchdog, Worktree
- **테마**: Glass/Light/Dark 전환
- **보안 경계**: 미인증 WebSocket 요청 거부, 외부접속 제한 모드 자동 진입, 외부 OTP 요청 차단, 외부 인증/시크릿/외부접속 설정 차단 메시지 구분, 외부 대화/코딩/루틴/로직 그래프 실행 차단, 외부 읽기 중심 조회와 모델/라우팅 설정 허용, WebSocket Origin 검사, 루틴 이미지 프리뷰 경로 제한, 첨부 개수/크기 초과 reject, Markdown raw HTML 차단
