# 검증 가이드

[한국어](./검증_가이드.md) · [English](./en/validation.md)

업데이트 기준: 2026-09-12

기능을 바꿨다면 최소한 아래 순서로 확인한다.

## 기본 검증

| 명령 | 기대 결과 |
|---|---|
| `npm test` | 저장소 위생, 계약 검사, 미들웨어 빌드/단위 테스트, 게이트웨이 런타임, 샌드박스 통과 (`[test] ok`) |
| `./scripts/omnux setup` | 의존성 확인/설치, 빌드, `npm test`, 실행기 등록 |
| `curl -s http://127.0.0.1:41880/readyz` | `"ready":true` |
| `dotnet run --project apps/omnux-middleware/Omnux.Middleware.csproj -- doctor --json` | 순수 JSON doctor 보고서 |

Windows는 `.\scripts\omnux.ps1 setup`을 쓴다.

## npm test 단계

`scripts/run-omnux-tests.mjs`가 아래 순서로 실행하고, 하나라도 실패하면 멈춘다.

| 묶음 | 스크립트 |
|---|---|
| 공유 카탈로그 | `apps/shared/audit-renewal.test.mjs`, `apps/shared/model-registry.test.mjs`, `apps/shared/generate-cs-registry.js --check` |
| 저장소/경계 | `check-repo-hygiene`, `check-core-daemon-boundary-contract`, `check-desktop-shell-boundary-contract`, `check-security-boundaries`, `check-extension-wiring-contract`, `check-tech-stack-contract` |
| 화면 모델 | `check-activity-screen`, `check-insights-screen`, `check-operations-screen`, `check-routing-screen`, `check-agents-screen`, `check-review-screen`, `check-skills-screen` |
| 워크스페이스 소스 | `check-build/chat/explore/automation/task-workspace-source`, `check-renewal-screens`, `check-ui-slop` |
| 런타임 계약 | `check-coding-python-game-contract`, `check-browser-intent-contract`, `check-chat-telegram-contract` |
| .NET | 미들웨어 빌드, `apps/omnux-middleware-tests` 단위 테스트 |
| 게이트웨이 | `check-gateway-runtime-contract` (격리 미들웨어 + Playwright Chromium) |
| 샌드박스 | `apps/omnux-sandbox/executor.py` smoke |

화면 모델 검사는 `.ts`를 직접 불러온다. TypeScript 타입 제거 없이 빌드된 Node(Ubuntu 배포판 패키지 등)에서는 러너가 `scripts/typescript-loader.mjs`를 자동으로 붙인다.

## 데스크톱 검증

```bash
npm run build --prefix apps/desktop
omnux
```

`omnux`는 vite(1420)와 Tauri 셸을 띄우고, 셸이 미들웨어(41880)를 함께 실행한다.

## 화면 검사 (Playwright)

`npm test`를 한 번 돌린 뒤(게이트웨이 픽스처 생성), vite가 `127.0.0.1:1420`에서 응답할 때 실행한다. `omnux`로 띄웠거나 `OMNUX_DESKTOP_UI_HOST=127.0.0.1 npm run dev --prefix apps/desktop`으로 띄운다. macOS에서 기본 `localhost`는 IPv6에만 붙는다.

| 스크립트 | 검사 내용 |
|---|---|
| `run-workspace-ui-checks.mjs` | 질문/빌드/자동화/탐색/작업 화면 흐름 |
| `check-desktop-launch.mjs` | 첫 실행과 재실행 |
| `check-viewport-fit.mjs` | 1440/768/390/320 폭 맞춤 |
| `check-provider-model-defaults.mjs` | 설정의 모델 기본값 |
| `audit-all-screens.mjs` | 모든 화면의 가로 넘침과 스크린샷 |

스크린샷과 로그는 `output/playwright/` 아래에 남는다.
