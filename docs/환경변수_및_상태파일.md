# 환경변수와 상태 파일

[한국어](./환경변수_및_상태파일.md) · [English](./en/environment-and-state.md)

업데이트 기준: 2026-09-12

설정과 대화 기록은 `~/.omnux`, 실제 작업 결과는 `workspace/`에 둔다. 상태 디렉터리는 `~/.omnux` 하나만 쓴다. 환경변수는 `OMNUX_*`만 읽고, 현재 `OMNUX_*` 변수는 159개다. 아래 표는 그중 자주 쓰는 것만 추렸다.

## 시크릿

| 변수 | 의미 |
|---|---|
| `OMNUX_GEMINI_API_KEY_FILE` | Gemini 키 파일 |
| `OMNUX_GROQ_API_KEY_FILE` | Groq 키 파일 |
| `OMNUX_CEREBRAS_API_KEY_FILE` | Cerebras 키 파일 |
| `OMNUX_NVIDIA_API_KEY_FILE` | NVIDIA NIM 키 파일 |
| `OMNUX_CODEX_API_KEY_FILE` | Codex API 키 파일 |
| `OMNUX_TELEGRAM_BOT_TOKEN_FILE` | 텔레그램 봇 토큰 파일 |
| `OMNUX_*_KEYCHAIN_SERVICE`, `OMNUX_*_KEYCHAIN_ACCOUNT` | macOS Keychain 항목 지정 |

키 문자열을 `OMNUX_GROQ_API_KEY`처럼 환경변수에 직접 넣을 수도 있지만, 운영에서는 `*_FILE`이나 secure store를 쓴다.

```bash
mkdir -p "$HOME/.omnux/keys"
printf 'YOUR_GROQ_KEY' > "$HOME/.omnux/keys/groq_api_key"
chmod 600 "$HOME/.omnux/keys/groq_api_key"
export OMNUX_GROQ_API_KEY_FILE="$HOME/.omnux/keys/groq_api_key"
```

## 모델

| 변수 | 기본값 |
|---|---|
| `OMNUX_GEMINI_MODEL` | 모델 레지스트리 기본값, 현재 `gemini-3.5-flash-lite` |
| `OMNUX_GEMINI_FLASH_MODEL` | `gemini-3-flash-preview` |
| `OMNUX_GEMINI_FLASH_LITE_MODEL` | 검색 보조용 `gemini-3.1-flash-lite` |
| `OMNUX_GROQ_MODEL`, `OMNUX_CEREBRAS_MODEL`, `OMNUX_NVIDIA_MODEL`, `OMNUX_COPILOT_MODEL`, `OMNUX_CODEX_MODEL`, `OMNUX_GROK_MODEL` | `apps/shared/model-registry.json`의 provider별 기본값 |

## 경로와 동작

| 변수 | 의미 |
|---|---|
| `OMNUX_STATE_DIR` | 상태 루트 override (기본 `~/.omnux`) |
| `OMNUX_WORKSPACE_ROOT` | 작업공간 루트 override (기본 저장소의 `workspace/coding`) |
| `OMNUX_PROJECT_CONTEXT_FALLBACK_FILENAMES` | AGENTS가 없을 때 읽을 지침 파일 (기본 `TEAM_GUIDE.md,.agents.md`) |
| `OMNUX_ENABLE_DYNAMIC_CODE` | 로컬 코드 실행 허용 여부 |
| `OMNUX_ENABLE_LOCAL_OTP_FALLBACK` | 로컬 OTP fallback (기본 켜짐) |
| `OMNUX_GATEWAY_STARTUP_PROBE` | gateway 시작 probe |
| `OMNUX_TELEGRAM_CHAT_ID` | 봇이 응답할 단일 chat_id |
| `OMNUX_TELEGRAM_ALLOWED_USER_ID` | 허용 user_id. 콤마·세미콜론·공백으로 여럿 지정 (`"123,456"`) |
| `OMNUX_BROWSER_TOOL_MODE` | `auto`(기본), `playwright`, `off`. 옛 `stub` 값은 비활성 오류를 반환한다 |
| `OMNUX_CANVAS_TOOL_MODE` | `auto`(기본), `playwright`, `off`. 옛 `stub` 값은 비활성 오류를 반환한다 |
| `OMNUX_BROWSER_CHANNEL` | Chromium 계열 채널. 비우면 Playwright Chromium, 없으면 설치된 Chrome |
| `OMNUX_BROWSER_HEADLESS` | Playwright headless 실행 여부 (기본 `true`) |

## 상태 저장소 인벤토리

JSON 상태 저장소는 가능한 경우 `AtomicFileStore`를 통해 파일별 `.lock` lease를 잡고 원자 교체한다. 기존 정상 파일은 같은 경로의 `.bak`로 남는다. 아래 표의 "원자 쓰기 + 백업 복구"는 primary JSON이 손상됐을 때 `.bak`를 검증하고 primary를 복구하는 읽기 경로까지 있다는 뜻이다.

| 상태 | 기본 위치 | override | 처리 기준 |
|---|---|---|---|
| 대화·스킬 활성 상태 | `~/.omnux/conversations.json` | `OMNUX_CONVERSATION_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| 인증 세션 | `~/.omnux/auth_sessions.json` | `OMNUX_AUTH_SESSION_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| 루틴 정의 | `~/.omnux/routines.json` | `OMNUX_ROUTINE_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| LLM 사용량 | `~/.omnux/llm_usage.json` | `OMNUX_LLM_USAGE_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| Copilot 사용량 | `~/.omnux/copilot_usage.json` | `OMNUX_COPILOT_USAGE_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| 라우팅 정책 override | `~/.omnux/routing-policy.json` | 없음 | 원자 쓰기 + 백업 복구 |
| 계획 index·본문·리뷰·실행 기록 | `~/.omnux/plans/index.json`, `~/.omnux/plans/<planId>/*.json` | 없음 | 원자 쓰기 + 백업 복구 |
| Task graph index·본문 | `~/.omnux/tasks/index.json`, `~/.omnux/tasks/<graphId>.json` | 없음 | 원자 쓰기 + 백업 복구 |
| Telegram reply outbox | `~/.omnux/telegram_reply_outbox.json` | 없음 | 원자 쓰기 + 백업 복구 |
| Guard retry timeline | `~/.omnux/guard_retry_timeline.json` | `OMNUX_GUARD_RETRY_TIMELINE_STATE_PATH` | 원자 쓰기 + 백업 복구 |
| Gateway health snapshot | `~/.omnux/gateway_health.json` | `OMNUX_GATEWAY_HEALTH_STATE_PATH` | 원자 쓰기, 읽기 복구 없음 |
| Gateway startup probe snapshot | `~/.omnux/gateway_startup_probe.json` | `OMNUX_GATEWAY_STARTUP_PROBE_STATE_PATH` | 원자 쓰기, 읽기 복구 없음 |
| 외부접속 설정 | `~/.omnux/dashboard_access.json` | `OMNUX_DASHBOARD_ACCESS_STATE_PATH` | 원자 쓰기, 읽기 복구 없음 |
| Doctor 마지막 결과·히스토리 | `~/.omnux/doctor/last-report.json`, `~/.omnux/doctor/history/*.json` | 없음 | 원자 쓰기, 읽기 복구 없음 |
| Safe Refactor preview | `workspace/.runtime/refactor-preview/*.json` | 없음 | 원자 쓰기, TTL 기반 임시 상태 |
| Logic graph 실행 snapshot | `workspace/.runtime/logic/<graphId>/<runId>/snapshot.json` | 없음 | 실행 산출물, 읽기 복구 없음 |
| Task graph 실행 stdout·stderr·result | `workspace/.runtime/tasks/<graphId>/<taskId>/` | 없음 | 실행 산출물, 읽기 복구 없음 |
| 노트북 문서 | `~/.omnux/notebooks/<projectKey>/*.md` | 없음 | 원자 쓰기, Markdown 문서 |
| 메모리 노트 | `~/.omnux/memory-notes/*.md` | `OMNUX_MEMORY_NOTES_DIR` | 원자 쓰기, Markdown 문서 |

`doctor --json`의 `workspace` 체크는 상태 루트의 JSON, `.bak`, `.lock`, 손상 JSON 개수를 보고한다. 손상 JSON이 있으면 `corruptJsonFiles=상대경로:backup=yes|no` 형식으로 백업 존재 여부도 함께 내놓는다.
